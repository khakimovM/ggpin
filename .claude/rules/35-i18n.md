# i18n rules — Uzbek + Russian (always active)

- Two locales: `uz` (default, Latin script) and `ru`. Catalogs: `packages/i18n/uz.json`,
  `packages/i18n/ru.json`. Web, admin, bot, and API error messages all read from them.
- No hardcoded user-facing string anywhere. Add the key to BOTH files in the same change.
- Key style: `area.screen.element` (e.g. `store.product.confirmRecipient`). ICU plurals for
  counts (`{count, plural, one {...} other {...}}`) — Russian needs one/few/many.
- Uzbek: use ‘ (U+2018) in o‘ g‘ and ʼ (U+02BC) for tutuq belgisi, consistently.
- Dates/numbers through `Intl` with the active locale; money via `formatMoney`.
- Product names that are brands (PUBG Mobile, Telegram Premium) are not translated.
- A test asserts that uz and ru have identical key sets.
- Admin panel UI: Uzbek only (owner/operators), but it must display user content in either language.
